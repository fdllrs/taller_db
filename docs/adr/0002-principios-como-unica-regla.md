# `DEVELOPMENT-PRINCIPLES.md` es la única regla para el código de pádel

`system-definition/CLAUDE.md` todavía pide TDD, criterios de `@ts-expect-error` y `multilang`, pero esas exigencias ya no están en `DEVELOPMENT-PRINCIPLES.md`. Ante una diferencia manda `DEVELOPMENT-PRINCIPLES.md`: el código de pádel lleva tests con cobertura, sin TDD obligatorio. Lo que `ssot2026` no cumple se resuelve con mejoras genéricas aparte, que no bloquean la app, y el Front de Administración arranca con esas faltas.
