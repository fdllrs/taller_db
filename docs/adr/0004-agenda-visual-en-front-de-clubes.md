# El Front de Clubes usa una agenda visual en lugar de grillas

La Parte II §5 pide grillas tipo planilla, pero el Front de Clubes tiene que ser visualmente atractivo. Decidimos dejar las grillas para el Front de Administración y darle al Front de Clubes una agenda con una columna por Cancha y un día por vista. El widget único de navegación y la URL con estado siguen valiendo en todos los frontends.
